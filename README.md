# Data-Science-Seminars-and-Challenge
### assignment
- Exploratory Data Analysis
- State of the art review
- Banchmarking
- Predictive models

  --> Students are expected to *study existing approaches* in ITSM analytics, ticket classification, SLA prediction, and time-to-resolution modeling, then *compare several machine learning or statistical methods on the provided dataset*.

  Expected outcomes
- State of art: 1 or 2 papers
- Compare 2 baselines .
- Try to define a model that predict both outcomes at the same time.
- Try to improve existing baselines

## work-flow split
- Exploratory Data Analysis: outlier detection, distribution, missing values,...
- Find papers on ITSM analytics, ticket classification, SLA prediction, and time-to-resolution modeling
- ....
